# Loan Approval Prediction using Logistic Regression

A Machine Learning web application built with **Python**, **Scikit-learn**, and **Streamlit** to predict whether a loan application is likely to be approved.

## Features
- Loan Approval Prediction
- Approval Probability
- Interactive Streamlit Interface

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
